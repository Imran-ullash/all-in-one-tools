How to Use the Image Resizer

1
Step 1

Select or drag your image file into the dropzone.

2
Step 2

Enter your desired width or height in pixels. With "Lock Aspect Ratio" checked, the other dimension updates automatically.

3
Step 3

Select your output file format (PNG, JPEG, or WebP) and click Download.

How It Works & Underlying Formula

An HTML5 Canvas element is instantiated with the target dimensions. The image is rendered with high-quality bicubic scaling enabled (`ctx.imageSmoothingQuality = "high"`), producing crisp resized graphics ready for websites and apps.
